# JumpServer for DeepSeek Harness

在 DeepSeek Harness（DSH）对话中，让 Agent 通过 JumpServer 查找你有权访问的资产、执行命令和传输文件。需要交互操作时，你可以接管终端。

## 使用

1. 在 DSH 插件管理中安装插件的 `.tgz` 包，重启对应的 DSH profile。
2. 打开左侧 **JumpServer**，保存站点地址，点击 **浏览器授权** 完成登录。
3. 在对话里试试：“列出我能访问的测试主机，等我选一台，再查它的磁盘使用情况。”
